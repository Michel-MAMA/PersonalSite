# PersonalSite

Site personnel de Dr. Michel MAMA TOULOU, consacré à ses expertises en data, intelligence artificielle et cloud, ses accompagnements, ses certifications et ses publications.

## Déployer sur Vercel

Le site est statique : il est servi directement depuis la racine du dépôt, sans commande de build ni dépendance à installer. La configuration Vercel se trouve dans `vercel.json` et active aussi les URLs sans suffixe `.html`.

Pour le premier déploiement, importez le dépôt GitHub `Michel-MAMA/PersonalSite` dans Vercel. Gardez la racine du dépôt comme répertoire du projet, avec le framework **Other**. Après connexion du dépôt, les prochains commits sur `main` pourront déclencher un nouveau déploiement.

## Avant publication

Configurez l’adresse de contact dans `script.js`. Le formulaire ouvre le logiciel de messagerie du visiteur ; les pièces jointes doivent être ajoutées manuellement au message.

Consultez `BLOG.md` pour ajouter une publication.
