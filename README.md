# PersonalSite

Site personnel de Dr. Michel MAMA TOULOU, consacré à ses expertises en data, intelligence artificielle et cloud, ses accompagnements, ses certifications et ses publications.

## Lancer le site

Le site est statique : ouvrez `index.html` dans un navigateur ou publiez le contenu de ce dépôt sur un hébergeur de sites statiques.

Avant publication, configurez l’adresse de contact dans `script.js`. Le formulaire ouvre le logiciel de messagerie du visiteur ; les pièces jointes doivent être ajoutées manuellement au message.

Consultez `BLOG.md` pour ajouter une publication.
